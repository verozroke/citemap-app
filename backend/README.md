# citemap-api

Backend of CiteMap: a FastAPI service that builds citation networks around a
seed paper (from a bundled demo dataset or from OpenAlex), ranks papers with
PageRank, groups them into topic clusters and serves the result to the web
frontend. Graph analysis is provided by
[citemap-core](https://github.com/verozroke/citemap-core).

See the repository README for installation and usage.
